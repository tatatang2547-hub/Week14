# Week14 - Data Visualization with Matplotlib

การทดลองสร้างและแสดงผลกราฟรูปแบบต่างๆ ด้วยภาษา Python โดยใช้ไลบรารี `matplotlib` และ `numpy` จัดวางกราฟ 9 รูปแบบลงในหน้าเดียวด้วย Subplots (3x3 Grid)

## รายการกราฟที่แสดง (3x3 Grid)
1. **Scatter Plot 1**: กราฟจุดแบบกระจายพร้อม Colorbar
2. **Scatter Plot 2**: กราฟจุดแบบกำหนดขนาดตามข้อมูล
3. **Horizontal Bar Chart**: กราฟแท่งแนวตั้ง/แนวนอน
4. **Sports Watch Data**: กราฟเส้นพร้อมเส้นตาราง (Grid)
5. **Zigzag Lines**: กราฟเส้นซิกแซกหลายเส้น
6. **Line with Markers**: กราฟเส้นเน้นจุดข้อมูล (Markers)
7. **Histogram**: กราฟแจกแจงความถี่ข้อมูล
8. **Pie Chart 1**: กราฟวงกลมแบบแยกชิ้นส่วน (Explode)
9. **Pie Chart 2**: กราฟวงกลมพร้อมสัญลักษณ์อธิบาย (Legend)
